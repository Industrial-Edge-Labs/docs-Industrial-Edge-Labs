## Highlights

- Portable plant simulator with optional ZeroMQ FSM input.
- RK4 solver aligned with the generated artifacts from [symbolic-to-numeric-computation-pipeline](https://github.com/Industrial-Edge-Labs/symbolic-to-numeric-computation-pipeline).
- Deterministic CSV output for local analysis and plant-facing experiments.
