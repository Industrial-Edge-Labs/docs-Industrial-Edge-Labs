## Highlights

- Canonical `InferencePayload` input aligned with [event-driven-vision-processing-engine](https://github.com/Industrial-Edge-Labs/event-driven-vision-processing-engine).
- Canonical `InspectionAnomalyPayload` input aligned with [industrial-visual-inspection-engine](https://github.com/Industrial-Edge-Labs/industrial-visual-inspection-engine).
- Configurable `FsmPayload` publication endpoint aligned by default with [edge-ai-system-orchestrator](https://github.com/Industrial-Edge-Labs/edge-ai-system-orchestrator).
- Portable dry-run mode for validating both input branches without ZeroMQ.
